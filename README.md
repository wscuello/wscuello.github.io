# wscuello.github.io

Personal academic website for William S. Chang-Cuello.

## Files

- `index.html` — homepage
- `research.html` — research overview and selected publications
- `teaching.html` — teaching page
- `contact.html` — contact page
- `assets/css/style.css` — main stylesheet
- `assets/img/` — image assets and favicon
- `assets/files/WSC_CV.pdf` — CV

## GitHub Pages

For a user site, this repository should be named:

```text
wscuello.github.io
```

Push these files to the main branch, then enable GitHub Pages in the repository settings if it is not already enabled.
